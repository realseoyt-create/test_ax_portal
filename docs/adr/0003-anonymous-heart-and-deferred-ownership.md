# Anonymous cookie-based hearts, no edit/delete in v1

v1에는 로그인이 없다. 하트 중복 방지는 서버가 발급하는 익명 쿠키 ID로 처리한다(localStorage만 쓰면 기기 변경 시 무력화되고 검증이 안 됨).

같은 이유로 v1에서는 등록된 시스템의 수정·삭제 기능을 아예 제공하지 않는다 — 로그인이 없는 상태에서 "누가 고칠 수 있는가"를 정의할 방법이 없기 때문이다. 다만 시스템 테이블에는 `ownerId`/관리자 권한을 위한 필드를 미리 마련해두어, 추후 SSO가 도입되면 소유자·관리자 기반의 수정/삭제 기능을 별도 마이그레이션 없이 추가할 수 있게 한다.
